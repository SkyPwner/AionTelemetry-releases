# AION 2 — игровая панель

**[Скачать установщик для Windows x64](https://github.com/SkyPwner/AionTelemetry-releases/releases/download/v1.0.54/AionTelemetry-Setup-1.0.54.exe)** · [Все версии](https://github.com/SkyPwner/AionTelemetry-releases/releases)

## Установка

1. Скачайте Setup.exe и пройдите мастер установки.
2. Если мастер попросит, установите компоненты. WebView2 подготавливается по нажатию кнопки; для Npcap мастер открывает [официальную страницу](https://npcap.com/#download), после установки нажмите «Проверить снова».
3. Откройте ярлык **AionLens** на рабочем столе или в меню «Пуск». Главная и оверлеи запускаются вместе; CMD и отдельная установка Python/.NET/PowerShell7 не нужны.

Npcap — драйвер для получения сетевых событий AION 2: по ним приложение считает живые DPS, лечение и эффекты. Он устанавливается отдельно один раз: бесплатная лицензия не позволяет включить его в наш пакет. Не выбирайте ограничение Npcap «только для администраторов»: приложение запускается с обычными правами.

## Возможности

DPS и лечение, эффекты с длительностью и перезарядкой, события, профиль с экипировкой, карта и компас петов/скрытых кубов. История боёв хранится на вашем ПК. Личные данные и пользовательские базы в установщик не включены; в этот GitHub-репозиторий они не отправляются.

## Обновления

В «Главная → Что нового» нажмите **«Обновить и перезапустить»**. Программа скачает и проверит подписанное обновление, применит его без мастера и запустится снова. История и настройки сохраняются. При ошибке установки частичный пакет не запускается. Старые версии используют прежний ручной сценарий или ZIP; переход из старой переносной папки автоматически не переносит её историю.

Манифесты обновлений подписаны RSA-3072-PSS/SHA-256; размер и SHA-256 загрузки проверяются. Стабильные релизы неизменяемы. EXE пока не имеет Authenticode-сертификата издателя, поэтому Windows может показать предупреждение неизвестного издателя.

## Совместимость

Windows x64; основная проверенная среда Windows11. Для Windows10 требуется поддерживаемая .NET10 редакция и обновления. Linux, macOS, Windows7/8 и 32-битная Windows не поддерживаются. Протокольная основа закреплена к Steam Global build25926599; статические привязки полевых боссов дополнительно проверены для26077854. Это не подтверждает все события нового клиента; патчи могут потребовать обновления. Проверка на каждом классе и втором физическом ПК отдельно не заявляется.

Обычные настройки находятся в приложении. Точные таймеры полевых боссов загружаются после открытия в игре **M → Исследование → Полевые боссы** нужного региона.
