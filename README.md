# AION 2 — игровая панель

**[Скачать установщик для Windows x64](https://github.com/SkyPwner/AionTelemetry-releases/releases/download/v1.0.43/AionTelemetry-Setup-1.0.43.exe)** · [Все версии](https://github.com/SkyPwner/AionTelemetry-releases/releases)

## Установка

1. Скачайте Setup.exe и пройдите мастер установки.
2. Если мастер попросит, установите компоненты. WebView2 подготавливается по нажатию кнопки; для Npcap мастер открывает [официальную страницу](https://npcap.com/#download), после установки нажмите «Проверить снова».
3. Откройте ярлык **AION 2** на рабочем столе или в меню «Пуск». Главная и оверлеи запускаются вместе; CMD и отдельная установка Python/.NET/PowerShell7 не нужны.

Npcap устанавливается отдельно один раз: бесплатная лицензия не позволяет включить его в наш пакет. Не выбирайте ограничение Npcap «только для администраторов»: приложение запускается с обычными правами.

## Возможности

DPS и лечение, эффекты с длительностью и перезарядкой, события, профиль с экипировкой, карта и компас петов/скрытых кубов. История боёв хранится на вашем ПК. Личные данные и пользовательские базы в установщик не включены; в этот GitHub-репозиторий они не отправляются.

## Обновления

Приложение уведомляет о новой версии. По вашему нажатию скачивает и проверяет подписанный файл. Затем вы сами открываете папку и запускаете новый установщик. **Автоматического запуска, установки обновления или перезапуска нет.** При обновлении в ту же установленную папку история и настройки сохраняются. Старые переносные версии продолжают получать ZIP; переход в установленную версию автоматически не переносит историю старой папки.

Манифесты обновлений подписаны RSA-3072-PSS/SHA-256; размер и SHA-256 загрузки проверяются. Стабильные релизы неизменяемы. EXE пока не имеет Authenticode-сертификата издателя, поэтому Windows может показать предупреждение неизвестного издателя.

## Совместимость

Windows x64; основная проверенная среда Windows11. Для Windows10 требуется поддерживаемая .NET10 редакция и обновления. Linux, macOS, Windows7/8 и 32-битная Windows не поддерживаются. Данные закреплены за Steam Global build25926599; изменения игрового протокола после патча могут потребовать обновления. Проверка на каждом классе и втором физическом ПК отдельно не заявляется.

Обычные настройки находятся в приложении. Точные таймеры полевых боссов загружаются после открытия в игре **M → Исследование → Полевые боссы** нужного региона.
