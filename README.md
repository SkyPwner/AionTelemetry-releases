# AION Telemetry

Игровая панель для AION 2: DPS и лечение, эффекты, таймеры, карта питомцев и скрытых кубов, экипировка и история боёв.

## Скачать

Последняя версия находится в [Releases](https://github.com/SkyPwner/AionTelemetry-releases/releases/latest).

1. Скачайте полный `AionTelemetry-portable-win-x64-*.zip` и распакуйте его целиком.
2. Нужна Windows x64. Установите [Npcap](https://npcap.com/#download) и при необходимости [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/).
3. Запустите `Start-AionTelemetry.cmd`. Python и .NET уже включены.

Перед сменой версии закройте приложение и запустите `Stop-Monitor.ps1` и `Stop-Collector.ps1` из старой папки. Сохраните эту папку с историей; новая распаковка имеет собственные данные. Не смешивайте базы вручную.

## Обновления и данные

Приложение проверяет подписанный манифест и размер/SHA-256 ZIP. Неподписанные или изменённые обновления отклоняются. После загрузки можно открыть папку; архив не запускается и не распаковывается автоматически.

Подпись: RSA-3072-PSS/SHA-256. Закрытый ключ отсутствует в приложении и GitHub. Публичный SPKI fingerprint: `32016fc831fc8196d69e9d96155d9ca226ac71d088641b2f21f9a19dabdba8e1`.

Исполняемые файлы пока не имеют Authenticode-сертификата Windows. Первую установку получайте из доверенного источника. Подпись обновлений не заменяет защиту компьютера издателя.

Сборки общедоступны; игровые данные пользователей сюда не отправляются. История боёв и настройки остаются локальными. Global и корейские игровые патчноуты в «Что нового» показаны отдельно.

В этом репозитории находятся только материалы выпуска. Полная рабочая копия проекта, личные данные и журналы не публикуются.
